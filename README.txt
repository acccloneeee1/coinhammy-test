COINHAMMY – BẢN XUẤT WEB TĨNH (28 trang)

Cách đưa lên web
- Tải nguyên thư mục này lên hosting (thư mục public_html của cPanel, hoặc kéo thả vào Netlify / Vercel / Cloudflare Pages).
- Trang chủ là index.html. Các trang liên kết với nhau bằng đường dẫn tương đối nên không cần sửa gì thêm.
- Không cần máy chủ đặc biệt: toàn bộ là HTML tĩnh, CSS và JS nằm sẵn trong từng file.

Lưu ý trước khi chạy thật
- Nút "Mở tài khoản" / "Xem sàn" hiện trỏ tới trang chủ của sàn kèm mã theo dõi utm, CHƯA có mã giới thiệu (ref) của anh.
  Khi có link giới thiệu, gửi lại để gắn vào bảng AFFH rồi xuất lại.
- Giá coin, khối lượng và phí đang là số tĩnh (kiểm tra lần cuối 10/2026); phần cần API sẽ làm sau.
- Phông chữ tải từ Google Fonts, cần có mạng khi mở trang.
